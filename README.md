# DeltaForce Android 助手

手机端原生 Android 客户端，连接你自己部署的 DeltaForce PHP API。

## 手机生成 APK
1. 打开本仓库的 **Actions**。
2. 选择 **Build Android APK**。
3. 点 **Run workflow**。
4. 构建完成后进入对应任务，在 **Artifacts** 下载 `DeltaForce-debug-apk`。
5. 手机上解压 APK 并安装。

## 使用
首次打开后，在“设置”填写你的 API 地址，例如：
`https://你的服务器地址/`

不要把 QQ/微信 Cookie、Token 或密码发给任何人。客户端只把登录流程所需数据发送到你自己填写的 API 服务器。
